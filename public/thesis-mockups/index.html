Макеты интерфейса (глава 2.2)

Цвета и стиль совпадают с src/theme/colors.ts и src/app/globals.css (палитра «Пульт VSAT»). Каждый файл — холст 1920×1080. PNG можно сгенерировать командой npm run thesis:mockups-png (нужны playwright и один раз npx playwright install chromium) — файлы появятся рядом, с именами fig-2-*-*.png. Либо откройте HTML в браузере и сделайте скриншот вручную.
